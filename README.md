# Учёт ТМЦ (TmcSklad)

Настольная программа для Windows (C#, WPF) для учёта товарно-материальных ценностей: приход на склад, выдача сотрудникам с готовым актом в Word, остатки с выгрузкой в Excel, права доступа по категориям.

## Документация

В папке [`docs`](docs) лежит **инструкция для пользователя** — [`docs/Инструкция_пользователя.pdf`](docs/Инструкция_пользователя.pdf): вход, приход, выдача и акт, остатки, категории и номенклатура, пользователи, резервные копии, решение типовых проблем.

## Возможности

- **Приход** — поступление товара на склад (дата, товар, количество, примечание).
- **Выдача** — выдача одному получателю нескольких товаров; контроль остатка; акт по форме Ф-02 в `.docx`.
- **Остатки** — приход, расход и остаток по каждому товару, фильтр по категории, выгрузка в Excel (`.xlsx`).
- **Категории и номенклатура** — справочники товаров (для администратора).
- **Пользователи** — логины, пароли, права на выдачу по категориям (для администратора; пароли видны администратору).
- **Резервные копии** — автокопия при каждом запуске (30 последних), ручное создание копии и восстановление.

Остаток считается автоматически: **остаток = приход − расход**. Чтобы у товара появился остаток, его нужно оприходовать на вкладке «Приход».

## Быстрый старт

1. Войти: логин `admin`, пароль `admin` (первый вход).
2. Вкладка «Категории» — создать категорию.
3. Вкладка «Номенклатура» — добавить товар (название и единица измерения).
4. Вкладка «Приход» — оформить поступление, появится остаток.
5. Вкладка «Выдача» — оформить выдачу, акт откроется в Word.

Подробности — в инструкции из папки `docs`.

## Требования

- Windows 10 или 11 (64-разрядная).
- Для сборки из исходников — [.NET 10 SDK](https://dotnet.microsoft.com/download).
- Для открытия актов — Microsoft Word (или совместимый редактор `.docx`).
- Интернет для работы не нужен.

## Готовая программа (exe)

Можно сразу скачать и запустить готовую программу — **[`dist/TmcSklad.exe`](dist/TmcSklad.exe)**. Устанавливать .NET и собирать ничего не нужно: достаточно двойного щелчка по файлу. Файл также доступен на странице [Releases](https://github.com/amirgibadullin13-stack/TmcSklad/releases) и во вкладке Actions (артефакт `TmcSklad`). Он собирается автоматически при каждом обновлении кода.

## Запуск и сборка

```bash
dotnet run                # запуск из исходников (например, в VS Code)
```

Сборка одного exe-файла (на ПК с программой .NET не нужен):

```bash
build.bat                 # результат: publish\TmcSklad.exe (и копия в dist\)
```

## Где хранятся данные

| Что | Где |
| --- | --- |
| База данных | `data\db.json` рядом с `TmcSklad.exe` |
| Автокопии | `data\backups` (30 последних) |
| Акты выдачи | Рабочий стол → папка `Акты ТМЦ` (`Акт_0001.docx`, …); если недоступна — `data\acts` |

Для переноса на другой компьютер скопируйте `TmcSklad.exe` вместе с папкой `data`.

## Структура проекта

| Файл | Назначение |
| --- | --- |
| `App.xaml`, `App.xaml.cs` | запуск, общий стиль интерфейса |
| `MainWindow.cs` | главное окно и вкладки |
| `Ui.cs` | диалоги, таблицы, окна входа и выдачи |
| `Models.cs` | модели данных, хранилище, расчёт остатков |
| `ActDoc.cs` | заполнение шаблона акта `akt_template.docx` |
| `Xlsx.cs` | экспорт остатков в `.xlsx` без внешних библиотек |
| `akt_template.docx` | шаблон акта (форма Ф-02) |
| `docs/` | инструкция пользователя (PDF) |

## Безопасность

Пароли хранятся в базе `data\db.json` и показываются администратору. Защищайте папку с программой и резервные копии от посторонних.
